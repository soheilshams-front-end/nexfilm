# نکس فیلم (Next Film)

فرانت‌اند استریمینگ فارسی (RTL) با Next.js — دموی لوکال بدون بک‌اند.

## اجرا

```bash
npm install
npm run dev
```

## اسکریپت‌ها

- `npm run typecheck` / `npm run lint` — TypeScript
- `npm run test:smoke` — تست دود ژانر
- `npm run build` — بیلد production

## محیط

فایل نمونه: `.env.example`  
اختیاری: `NEXT_PUBLIC_SITE_URL` برای sitemap/robots.

## نکته

حساب، اشتراک، لیست من و prefs روی `localStorage` هستند.
